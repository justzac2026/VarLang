# VarLang
## Info
VarLang is a tool for modifying a Python program's runtime using an Inter-Process Communication (IPC) to communicate between the console and runtime.
## Installation
```bash
cd <VARLANG PATH>
chmod +x setup
./setup
```
## Usage
```bash
varlang runtime <FILE>
varlang console
varlang settings
varlang -h
varlang --help
```
